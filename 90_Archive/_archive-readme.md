# Archive

This folder preserves superseded decisions, deprecated notes, and retired project material without cluttering active navigation.

When archiving a note, set its `status` to `archived`, state why it was superseded, and include an Obsidian `[[wikilink]]` to its active replacement whenever one exists. Keep relevant MOC links so historical context remains discoverable.
